    入门学习路线¶

    第一步 · R 语言基础 2~3 周¶

    熟悉 R 的语法、数据结构与常用函数，先把「能读懂、能改写」作为目标。

    • R 语法视频（B 站）
    • 我有必要花大量时间去学习 R 语言绘图吗？

    第二步 · 绘图思想 3~5 天¶

    快速了解 ggplot2 的图层语法，不需要精通，够用即可。

    • R 语言数据可视化 —— 解读 ggplot2 绘图思想（B 站）
    • ggplot2 综合教程

    第三步 · 数据分析基础 1~2 周¶

    学会读入数据、整理数据、做基础统计与差异分析。

    • R 语言数据分析基础（B 站）
    • XSLiuLab Workshop 学习资源

    第四步 · 转录组与 TCGA 持续深入¶

    理解测序原理与文件格式，再从 counts / FPKM / TPM 出发做差异表达与富集分析。

    • 生物信息学入门必须了解的名词
    • illumina、Sanger、第三代和第四代测序技术原理
    • 生信中常见的数据文件格式

    延伸阅读¶

    转录组测序原理与上游分析流程

    了解转录组测序的基本原理，其中涉及的一些文件格式主要在上游分析中用到，知道即可。关于各种测序原理，可以在 B 站或微信搜索「陈巍学基因」，不需要掌握所有，普通转录组（bulk RNA-seq）先掌握，其他的结合自己需要了解，原理上很多是相通的。后面再了解单细胞测序技术和空间转录组技术。

    • 常用生物信息 ID 的介绍
    • 生信中各种 ID 转换
    • RNA-seq 的 counts、RPM、RPKM、FPKM 值到底有什么区别？
    • 《转录组基础知识》（密码：um4i）

    上游分析流程（基于 Linux）：

    • fastqc 进行质控与结果解读
    • 使用 trim-galore 去除低质量的 reads 和 adaptor
    • 使用 Hisat2 进行序列比对
    • 使用 SAMtools 将 SAM 转换为 BAM、排序与建索引
    • 使用 RSeQC 对 BAM 文件进行质控
    • 使用 StringTie 对数据进行下游处理
    • 曾健明老师教程（密码：y6a5ce）
