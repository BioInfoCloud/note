# 肿瘤TMB计算

<font style="color:rgb(0, 0, 0);">肿瘤突变负荷（Tumor Mutation Burden, TMB）通常指一份肿瘤样本中（肿瘤组织或外周血）全外显子测序或靶向测序所检测基因区域每兆碱基中发生的体细胞非同义突变或所有突变的数目（计算公式即：</font>**<font style="color:rgb(0, 0, 0);">突变个数/检测的外显子Mb长度</font>**<font style="color:rgb(0, 0, 0);">)。TMB计算的体细胞突变包括点突变和插入/缺失突变，</font>**<font style="color:rgb(0, 0, 0);">去除驱动突变（与肿瘤治疗、诊断、预后密切相关的突变，包括热点突变、药物靶点突变、癌基因功能激活突变和抑癌基因功能失活突变）</font>**<font style="color:rgb(0, 0, 0);">。由于TMB计算去除了可能影响免疫治疗效果的驱动突变，在极端情况下不排除出现 TMB=0 的可能。因而TMB = 0 仅表示检测样本在本产品的 TMB 分析方法的结果，并不等同于检测样本中没有突变。</font>
